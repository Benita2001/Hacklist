# Font licensing record

No fonts are bundled in this package.

The proposed review roles are:

- Newsreader for display typography.
- Manrope for interface typography.
- IBM Plex Mono for evidence and source metadata.

Before self-hosting or using these fonts in a distributed brand package, confirm the license terms, selected files, subset strategy, and owner approval. The application currently uses its existing font setup and is not changed by this review slice.
