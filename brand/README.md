# HackList brand package

This is the local engineering package for the HackList identity review.

Current status:

- The supplied compass PNG remains the only approved visual source.
- The token values are provisional digital-study values from `ui-artifacts/BRAND_KIT_PLAN.md`.
- No vector redraw, lockup, favicon, or production asset replacement is included.
- Logo authorship, modification rights, final color values, and font licensing remain owner decisions.

## Review surface

Run the HackList application locally and open `/brand`. The page is an internal engineering review surface for the supplied mark, provisional color roles, typography roles, and motion behavior. It is not a public launch page.

## Package map

- `provenance.md` records the source and unresolved rights decisions.
- `asset-inventory.md` records the current repository asset without modifying it.
- `tokens/brand.css` and `tokens/brand.json` contain the provisional digital token study.
- `fonts/LICENSES.md` records the proposed font strategy. Fonts are not bundled here.
- `guidelines/README.md` records the current usage rules and deferred approvals.
